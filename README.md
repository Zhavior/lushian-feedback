# Lushian beta feedback

This is where Lushian beta testers report problems and ideas. The app's source code is not here.

## How to send feedback

In Lushian, choose **Help ▸ Send Beta Feedback…**. Pick what kind of feedback it is, give it a title, then press **Open on GitHub**. A new issue opens here with your app version, build number and macOS version already filled in. Add what happened, then submit it.

You need a GitHub account to file an issue.

## Before you include a chat

Issues in this repository are public. Lushian adds the current chat to an issue only if you tick **Include the current chat**. Leave it off if the chat holds anything private: names, client details, prices or account information.
